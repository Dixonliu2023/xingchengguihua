# 路由判断矩阵与规则

## 路由判断标准

### 维度定义

| 维度 | 权重 | 评估标准 | 评分转换 |
|------|------|---------|---------|
| 目的地热度 | 20% | 热门(≥8分)/标准(5-7分)/小众(<5分) | 8分以上=20, 5-7分=10, <5分=0 |
| 需求复杂度 | 30% | 标准/定制化 | 标准=30, 定制化=0 |
| 客户类型 | 25% | 新客/老客/VIP | 新客=25, 老客=15, VIP=0 |
| 时间要求 | 25% | 即时/标准/宽松 | 即时=25, 标准=15, 宽松=0 |

### 路由判断逻辑

```
总评分 = 目的地热度评分 × 20% + 需求复杂度评分 × 30% + 客户类型评分 × 25% + 时间要求评分 × 25%

如果 总评分 ≥ 70：
  推荐工作流：快速生成流程
否则：
  推荐工作流：深度设计流程
```

## 详细评分规则

### 1. 目的地热度（20%）

**评分标准：**

| 评分 | 描述 | 示例目的地 |
|------|------|-----------|
| 20分 | 热门目的地（飞书知识库评分≥8分） | 北京、上海、大连、三亚 |
| 10分 | 标准目的地（飞书知识库评分5-7分） | 西安、成都、杭州 |
| 0分 | 小众目的地（飞书知识库评分<5分） | 边境小城、未开发景区 |

**判断方式：**
- 调用飞书MCP `search_destinations` 获取目的地 `avg_rating`
- 如果不存在于飞书知识库，默认为0分（小众）

---

### 2. 需求复杂度（30%）

**评分标准：**

| 评分 | 描述 | 特征 |
|------|------|------|
| 30分 | 标准需求 | 常见主题（亲子/情侣/家庭），常规天数（3-7天），无特殊要求 |
| 0分 | 定制化需求 | 小众主题（徒步/潜水/摄影），特殊天数（>10天），有特殊限制 |

**判断方式：**
- 主题是否在常见主题列表中（亲子、情侣、家庭、银发、朋友）
- 天数是否在3-7天范围内
- 是否有特殊限制（身体条件、预算限制、时间限制）

---

### 3. 客户类型（25%）

**评分标准：**

| 评分 | 描述 | 特征 |
|------|------|------|
| 25分 | 新客 | 首次咨询，需要快速响应建立信任 |
| 15分 | 老客 | 有合作历史，可以深度沟通 |
| 0分 | VIP | 重点客户，需要精心打磨产品 |

**判断方式：**
- 通过CRM或对话历史判断客户类型
- 如果无法判断，默认为新客（25分）

---

### 4. 时间要求（25%）

**评分标准：**

| 评分 | 描述 | 特征 |
|------|------|------|
| 25分 | 即时 | 需要立即响应（客户在线等待、紧急询价） |
| 15分 | 标准 | 需要当天内响应 |
| 0分 | 宽松 | 可以第二天或更久响应 |

**判断方式：**
- 检测用户对话中的时间紧迫性关键词（急、马上、今天、尽快）
- 默认为标准（15分）

## 路由示例

### 示例1：大连亲子游（新客咨询）

```
输入：
- 目的地：大连
- 天数：3天2晚
- 人群：一家三口，孩子4岁
- 主题：亲子游
- 客户类型：新客
- 时间要求：即时

评分计算：
- 目的地热度：20分（大连是热门目的地，飞书评分≥8分）
- 需求复杂度：30分（亲子游是标准需求，3天2晚在常规范围内）
- 客户类型：25分（新客）
- 时间要求：25分（即时）

总评分 = 20 + 30 + 25 + 25 = 100分

推荐工作流：快速生成流程 ✅
```

---

### 示例2：川藏线徒步（VIP客户）

```
输入：
- 目的地：川藏线
- 天数：15天
- 人群：徒步爱好者，4人
- 主题：徒步+摄影
- 客户类型：VIP
- 时间要求：标准

评分计算：
- 目的地热度：0分（川藏线徒步是小众主题）
- 需求复杂度：0分（15天超常规，徒步+摄影是小众主题）
- 客户类型：0分（VIP）
- 时间要求：15分（标准）

总评分 = 0 + 0 + 0 + 15 = 15分

推荐工作流：深度设计流程 ✅
```


### 推荐理由模板

#### 快速生成推荐理由

```
💡 推荐理由：

1. 目的地成熟度高
   - {destination}是热门目的地，飞书知识库数据完整
   - 玩法库覆盖度高，可快速匹配

2. 需求标准化
   - {theme}是常规需求，无需深度定制
   - {days}天行程在标准范围内

3. 响应速度快
   - 3-5分钟内可完成产品生成
   - 满足{timeline}要求

4. 首次咨询建议
   - 快速响应对建立客户信任有帮助
   - 后续可提供深度定制服务
```

#### 深度设计推荐理由

```
💡 推荐理由：

1. 定制化需求
   - {theme}是小众主题，需要深度设计
   - {days}天行程超出常规范围，需要精细规划

2. 目的地独特性
   - {destination}是小众目的地，玩法库数据有限
   - 需要从零开始挖掘资源

3. 客户价值高
   - VIP客户值得投入更多时间精心打磨
   - 深度设计可提升客户满意度和复购率

4. 产品差异化
   - 深度设计可形成独特产品竞争力
   - 适合打造标杆产品或独家线路
```

## 特殊情况处理

### 边界情况

| 情况 | 处理方式 |
|------|---------|
| 评分 = 70分 | 默认推荐深度设计，询问用户意见 |
| 飞书无该目的地数据 | 评分按小众处理（0分） |
| 客户类型未知 | 默认新客（25分） |
| 时间要求不明确 | 默认标准（15分） |

### 用户覆盖机制

如果用户明确要求特定工作流，以用户选择为准，不执行路由判断。
